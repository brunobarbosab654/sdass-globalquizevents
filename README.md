# sdass-globalquizevents

Static TikTok pay funnel for [globalquizevents.vercel.app](https://globalquizevents.vercel.app/).

- `/` redirects to `/inicio/`
- Funnel: `inicio` → quiz → withdraw → registration → upsells → thankyou / refund

Connect this repository to the Vercel project `globalquizevents` (root directory = repo root).
